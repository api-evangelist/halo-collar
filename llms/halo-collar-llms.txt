# Halo Collar

> Halo Collar is a consumer GPS dog-fence and dog-tracking product from Protect Animals With
> Satellites LLC (d/b/a Halo), founded in 2017 by Ken Ehrman, Michael Ehrman and dog
> behaviorist Cesar Millan. A cellular/GPS smart collar (Halo Collar 5, and Halo Collar 4)
> pairs with an iOS/Android app for virtual GPS fences, real-time tracking, Cesar
> Millan-designed training feedback and activity reports, on a required Pack Membership
> subscription in Bronze, Silver and Gold tiers.

## Status

Halo Collar publishes **no public API**. As of 2026-08-22 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/Protobuf/WSDL contract, no SDK, no CLI, no webhooks,
no MCP server and no A2A agent card anywhere on the company's public web properties.
`developer.halocollar.com` and `docs.halocollar.com` do not resolve in DNS. Probes for
`/llms.txt`, `/.well-known/security.txt`, `/.well-known/api-catalog`,
`/.well-known/openid-configuration`, `/.well-known/oauth-authorization-server`,
`/.well-known/ai-plugin.json`, `/.well-known/agent-card.json` and `/.well-known/agent.json`
returned 404 on `www.halocollar.com`, `api.halocollar.com` and `support.halocollar.com`.

There IS a first-party API host: `https://api.halocollar.com/` answers 200 with
`{"serviceName":"Halo.Web.Api","environment":"Production","version":"1.3.11.2"}` on Azure App
Service. It is the private backend for the Halo mobile app — undocumented, with no published
contract and no public reference — so it is recorded here as an observation, not as a
developer-facing API. Certificate transparency also names `halo-api.agents.halocollar.com` and
`halo.agents.halocollar.com`, both CNAMEd to `proxy.a.smyth.ai` (SmythOS, an AI agent
platform); neither host completes a TCP connection on 443 or 80.
